Install Ghostty with Homebrew, then open it.

```bash
brew install --cask ghostty
open -a Ghostty
```

Quit the built-in Terminal app and use Ghostty for every step after this one.
Inside Ghostty windows, the `ghostty` command is on your `PATH`, and later steps use it to check your setup.
