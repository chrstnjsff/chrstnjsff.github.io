Claude Code is Anthropic's coding assistant for the terminal: it reads your project, runs commands, and edits files with your permission.
The first steps install it and give it standing instructions.
The middle steps explain the commands you will use every day, each with an example and a way to stop it.
The last steps extend it with your own skills, subagents, rules and hooks, and with five community tools.
