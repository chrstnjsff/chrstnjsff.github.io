Create the folder for your notes:

```bash
mkdir -p ~/Notes
```

Then open it in Obsidian:

1. On the first screen, next to **Open folder as vault**, click **Open**.
   If a vault is already open, click the vault name at the bottom left, choose **Manage vaults...**, and find **Open folder as vault** there.
2. Select the `Notes` folder in your home folder, then click **Open**.

Obsidian names the vault after the folder, so this vault is called `Notes`.

Already have a vault?
Use its folder instead of `~/Notes` in every command in this guide.
